# HDS Price and Quantity Format

## Description

This module adjusts the decimal precision for quantities and unit prices in Odoo 18.

### Features

- **Quantities**: Reduced from 3 to 2 decimals
- **Unit Prices**: Reduced from 5 to 2 decimals
- Applies to:
  - Product templates
  - Sale order lines
  - Invoice lines (account move lines)

### Installation

This module is automatically installed when added to the addons path.

### Configuration

No configuration needed. The decimal precision is automatically applied upon module installation.

### Usage

After installing the module, all quantity and price fields will display only 2 decimal places instead of the default 3 or 5.
